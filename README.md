# MusicVerse-UIUX 🎧✨

MusicVerse is a modern music streaming mobile app UI/UX prototype designed using Figma.

The project focuses on creating a clean, minimal, and user-friendly music experience with smooth navigation and aesthetic layouts.

---

## 📌 Features

- Home Screen
- Featured Playlist Section
- Trending Songs
- Music Player Screen
- Search Functionality
- Bottom Navigation Bar
- Interactive Prototype Navigation

---

## 🎨 Design Style

- Minimal UI
- Soft Purple Theme
- Clean Typography
- Modern Music Streaming Layout
- Mobile-First Design

---

## 🛠 Tools Used

- Figma

The purpose of this project was to practice wireframing, UI/UX design principles, layout structuring, and interactive prototyping while designing a modern music streaming application.
